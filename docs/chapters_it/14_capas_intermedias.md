# Capitolo 14: I Layer Intermedi (6–12)

## I "layer di idee pure"

Nella lettura del progetto, la tratto medio dello stack
è dove il residuale diventa più **astratto**:
temi, ruoli, quadri (filosofico, narrativo, tecnico)
più che solo "la parola accanto".

```
Layer 6–12: concetti, contesto ampio, idee
```

## Perché contano per le prospettive

Le perturbazioni tipo `mystical` agiscono in **tutti**
i layer di attn/FFN. Il clima esistenziale che abbiamo visto
in prompt come *When we dissolve the ego* o
*The soul remembers* è compatibile con un residuale
già "tematizzato" nel mezzo del tunnel — non solo con
un ritocco cosmetico alla fine.

## Isole semantiche e il mezzo dello stack

Le direzioni dell'embedding (emotion, spirit, mind…)
non "finiscono" nel layer 0. Il residuale le **rimischia**.
Il tratto intermedio è candidato a essere dove
`--steer soul` smette di essere una spinta cosmetica
e diventa un bias tematico stabile.

## Esperimento suggerito

Proiettare attivazioni (se si istruisce il motore)
dei layer 6–12 sui baricentri spiritual / abstract / mind
e confrontare baseline vs mystical.
