# Kapitel 19: Die Zukunft der Erforschung

## Nächste technische Schritte

1. **Den Residual pro Schicht instrumentieren** in der C-Engine  
   (L0…L21-Sonden über emotion/spirit-Achsen).  
2. **UMAP/t-SNE** des Token-Himmels (wenn der Stack es erlaubt).  
3. **Residual / gradient / selective** nach `--perturb` portieren.  
4. **GGUF F16 der Schichten** nach F32-Kopie freigeben (weniger RAM).  
5. **GitHub Pages** nativ für die Karte (ohne htmlpreview).  
6. Die Kartierung in **einem anderen Modell** wiederholen (Transfer).

