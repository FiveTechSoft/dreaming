# Chapitre 14 : Les couches intermédiaires (6–12)

## Les « couches d’idées pures »

Dans la lecture du projet, la partie médiane de la pile
est là où le résiduel devient plus **abstrait** :
thèmes, rôles, cadres (philosophique, narratif, technique)
plutôt que juste « le mot d’à côté ».

```
Couches 6–12 : concepts, contexte élargi, idées
```

## Pourquoi elles importent pour les perspectives

Les perturbations de type `mystical` agissent sur **toutes**
les couches d’attn/FFN. Le climat existentiel que nous avons vu
dans des prompts comme *When we dissolve the ego* ou
*The soul remembers* est compatible avec un résiduel
déjà « théématisé » au milieu du tunnel — pas seulement avec
un retouche cosmétique à la fin.

## Îles sémantiques et milieu de la pile

Les directions de l’embedding (emotion, spirit, mind…)
ne « terminent » pas à la couche 0. Le résiduel les **remélange**.
La partie intermédiaire est candidat pour être là où
`--steer soul` cesse d’être une poussée cosmétique
et devient un biais thématique stable.

## Expérience suggérée

Projeter les activations (si le moteur est instrumentalisé)
des couches 6–12 sur les centroïdes spiritual / abstract / mind
et comparer baseline vs mystical.
